## Objetivo

Proyecto de ejemplo que demuestra el uso básico de las principales librerías de ciencia de datos en Python.

## Contenido

- `analisis_datos.py` — script principal de análisis
- `promedios.png` — gráfico generado al ejecutar el script

## Requisitos

- Python 3.8 o superior
- Librerías: NumPy, Pandas, Matplotlib

Instalación de dependencias:

```bash
pip install numpy pandas matplotlib
```

## Descripción

El script realiza las siguientes operaciones:

1. Crea un dataset de notas de estudiantes usando Pandas.
2. Calcula estadísticas descriptivas: media, mínimo, máximo y desviación estándar.
3. Genera una columna adicional con el promedio por estudiante.
4. Produce un gráfico de barras con Matplotlib y lo exporta como imagen PNG.

## Tecnologías

- NumPy: cálculo numérico
- Pandas: manipulación y análisis de datos
- Matplotlib: visualización de datos
